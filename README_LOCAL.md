# 兰斯 4 系列网页版

这是一个统一的静态网页项目，首页提供兰斯 4、兰斯 4.1、兰斯 4.2 的选择入口。它使用 WebAssembly 编译的原始 System 运行时：兰斯 4 使用 `xsystem35`，4.1 与 4.2 使用 `system3`。发布产物不依赖 Node.js API 或本机游戏路径。

## 启动

```sh
cd app
npm run local
```

在浏览器打开 `http://127.0.0.1:4173`，选择游戏即可启动。要生成与公开站点一致的完整静态资源，请运行：

```sh
npm run build-public
```

该命令会从以下原始游戏目录生成 `dist/games/`；该目录是部署产物，默认不提交到源码仓库。游戏数据位于本仓库同级目录的 `games/` 文件夹（可用环境变量 `GAMES_DIR` 覆盖）：

- `<repo>/../games/RANCE4`
- `<repo>/../games/RANCE4.1`
- `<repo>/../games/RANCE4.2`

4.1 和 4.2 的“提示盘”及附赠媒体会自动排除，避免与主游戏的 `ADISK.dat` 冲突；主游戏资源与 `bgm/` 音轨会被保留。

## 移动端操作（原型）

移动设备会在横屏进入游戏后自动显示掌机式控制层。游戏画面默认不会响应手指直接点击，以避免把滑动或误触送入原始运行时。

- 左侧十字键：移动选择或方向输入。
- `A`：确认、推进文字；在光标模式中确认当前位置的点击。
- `B`：第二操作（对应原游戏的 Space / 右键语义）。
- `光标`：主动进入或退出光标模式。此模式中在画面上滑动只移动光标，松手不会点击，必须按 `A` 才会确认。
- `菜单`：打开网页端设置和存档工具。

竖屏时会提示横屏游玩。桌面端保持键盘、鼠标和既有工具栏操作不变。开发验证可在地址后附加 `touch=1` 强制显示控制层。

## 攻略与修改器

这三个功能只对兰斯 4 / 4.1 / 4.2 生效（启动地址带 `?game=rance4|rance41|rance42`）。
《鬼畜王兰斯》不加任何新按钮，行为与之前完全一致。

**攻略**：工具栏的「攻略」按钮打开分章节中文攻略。内容在 `shell/guides/`，每篇都带来源列表；
每章可以手动标记完成，进度按作品存在浏览器本地，导航里会显示「✓」。

**修改器**：工具栏的「修改器」按钮打开，四个页签：

| 页签 | 作用 |
| --- | --- |
| 常用修改 | 已核对的固定变量（目前为空，见下）。 |
| 变量浏览 | 列出引擎当前的脚本变量（兰斯 4 有 65537 个、4.1/4.2 各 768 个），可按名字/编号筛选、直接改写、锁定。兰斯 4 的变量带 `System39.ain` 里的真实名字。 |
| 数值搜索 | 在游戏里记下数值 → 首次扫描 → 让数值变化 → 再次扫描，逐步缩小到唯一变量再改写；数值框留空则是「未知初始值」扫描。 |
| 存档备份 | 导出/恢复存档 ZIP。 |

实现方式是**运行期读写引擎自己的变量表**，不是猜内存地址：两套引擎都新增了一组
`cheat_*` 导出函数（`xsystem35-sdl2/src/cheat.c` 与 `system3-sdl2/src/emscripten/nact_emscripten.cpp`），
网页层通过 `shell/trainer.ts` 调用。

「常用修改」目前是空的，这是有意的：中/日/英文资料里**不存在**「金钱 = VAR_xxx」这类公开对照表，
而且新版兰斯 4 的地址会变动，按固定地址写内存不可靠。所以没有编造一组固定项，而是把
「数值搜索」做成主入口。核实过某个变量之后，可以把它加进 `shell/cheat-presets.ts`。

事实与验证记录见 [`tools/diag/NOTES-cheats.md`](tools/diag/NOTES-cheats.md)；
回归工具是 `node tools/diag/verify-cheats.mjs --game rance4|rance41|rance42`。

## 已验证

- 首页显示三个游戏选择项。
- 兰斯 4 使用 `xsystem35.wasm` 并进入标题画面。
- 兰斯 4.1 与 4.2 使用 `system3.wasm` 并进入各自标题画面。
- 浏览器存档由运行时的 IndexedDB 文件系统持久化。
- 三作均已加载统一移动端控制层；兰斯4已验证 `A` 推进游戏、光标模式与菜单，4.1、4.2 已验证启动与控制层加载。
- 修改器桥接在三作上全部通过：批量视图与逐项读取一致、写入可读回并还原、
  兰斯 4 的页号与既有 `_nact_current_page()` 一致、变量名与离线解出的 `System39.ain` 一致、
  在运行中的游戏里用「数值搜索」能把刚写入的值精确定位到唯一变量。
- 回归：鬼畜王兰斯仍能启动到序章，且工具栏没有新增按钮。
